# Edexcel GCSE Higher Maths checklist

Revision checklist for Pearson Edexcel GCSE Mathematics (1MA1), Higher tier. Topics group videos, worksheets and online practice from CorbettMaths, 1st Class Maths and Dr Frost Maths. Completion ticks are stored in the browser.

Run `python3 build.py` to regenerate `docs/index.html`. To preview the site, run `python3 -m http.server --bind 127.0.0.1 --directory docs` and open [the local preview](http://127.0.0.1:8000/). GitHub Pages publishes from `main` and `/docs`.

Worksheets open on their publishers’ sites and are subject to their terms. [CorbettMaths terms](https://corbettmaths.com/more/about/terms-of-use/) · [1st Class Maths copyright notice](https://www.1stclassmaths.com/copyrightnotice)
